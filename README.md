# SWAPSERVICE38

### Full-stack платформа для автомобильного сервиса, свапов и тюнинга

**Production:** https://swap38.ru

SWAPSERVICE38 — полноценное веб-приложение для автомобильного бизнеса, разработанное с нуля и запущенное в эксплуатацию.

Проект объединяет интернет-магазин автокомпонентов, каталог услуг, пользовательские аккаунты, систему заказов, онлайн-оплату и интеграцию с отдельной CRM-системой.

Это не учебный макет, а действующий коммерческий продукт с реальными пользователями, заказами и инфраструктурой.

---

## О проекте

Цель проекта — создать единую цифровую платформу для автомобильного сервиса, который специализируется на:

- Свапах двигателей и трансмиссий.
- Ремонте и обслуживании автомобилей.
- Производстве и продаже компонентов для тюнинга.
- Переоборудовании внедорожников.
- Установке и продаже автомобильных комплектующих.

Разработка охватывает полный цикл: от проектирования архитектуры и баз данных до развёртывания на собственном сервере, настройки безопасности, SEO и эксплуатации.

## Архитектура

Приложение разделено на независимые компоненты.

- **Frontend** — интерфейс пользователя.
- **Backend** — бизнес-логика, авторизация и API.
- **PostgreSQL** — постоянное хранение данных.
- **Redis** — временное кеширование.
- **CRM** — обработка заказов, складской учёт и внутренние операции.
- **nginx** — HTTPS и маршрутизация запросов.

Подробности: [ARCHITECTURE.md](ARCHITECTURE.md).

## Безопасность и данные

Приложение использует серверную валидацию, разграничение доступа, HTTPS и механизмы защиты пользовательских запросов.

Обработка персональных данных необходима для регистрации, оформления заказов, платежей и выполнения обязательств перед покупателями.

Подробная документация о хранении данных, сторонних интеграциях и мерах защиты будет опубликована отдельно.

## Запуск проекта

Для локального запуска необходимы Node.js, PostgreSQL, Redis и переменные окружения.

Подробная инструкция по установке и настройке будет добавлена в `docs/INSTALLATION.md`.
